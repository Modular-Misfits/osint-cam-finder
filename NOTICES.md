# NOTICES

## Origin

OSINT Camera Finder is derived from **Webanator**, an earlier project by Tony Maida (Modular Misfits).

The original Webanator codebase provided the initial Insecam scraping logic and project scaffolding. OSINT Camera Finder is a substantial rewrite and extension of that work, adding a full PyQt6 GUI, multi-source scanning, a persistent SQLite database, delta detection, a custom API source plugin system, parallel scanning, and JSON export.
